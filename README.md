# Qorynth（コリンス）

**P2P通信・閾値暗号・複数端末承認を組み合わせた分散鍵管理システム**

中央管理ノードを必要としない分散KMS / HSMであり、OpenBaoのAuto-Unsealを最初のユースケースとし、将来的には署名・暗号化・復号などの汎用的な鍵管理基盤を目指します。

## アーキテクチャ概要

```
┌─────────────────────────────────────────────────────────┐
│                    OpenBao Cluster                       │
│              (3ノード / Raft / Auto-Unseal)               │
│                   Bao A · B · C                         │
└────────────────────┬────────────────────────────────────┘
                     │ Auto-Unseal
                     ▼
┌─────────────────────────────────────────────────────────┐
│                  Qorynth Seal Gateway                    │
│              (2ノード / 認証 / フェイルオーバー)            │
└────────────────────┬────────────────────────────────────┘
                     │
        ┌────────────┼────────────┐
        │            │            │
        ▼            ▼            ▼
┌─────────────────────────────────────────────────────────┐
│                  Qorynth P2P Key Cluster                 │
│              (3ノード / 分散鍵管理 / クォーラム)             │
│              閾値暗号による 2-of-3 分散復号                │
└────────────────────┬────────────────────────────────────┘
                     │
  ┌──────────────────┼──────────────────┐
  │ (制御経路)        │ (制御経路)        │
  ▼                  ▼                  ▼
┌───────────┐ ┌───────────┐ ┌───────────┐
│ Signal A  │ │ Signal B  │ │ Signal C  │ │ ← 冗長Signaling
└───────────┘ └───────────┘ └───────────┘
  Peer Discovery / NAT Traversal / 接続補助

  承認端末（5台以上 / 3-of-5承認） ← 鍵処理のデータ経路ではない
```

> Signalingと承認端末は鍵処理のデータ経路ではなく、接続確立・有効化の制御経路に属します。

## コンポーネント

| コンポーネント | 台数 | 役割 |
|---|---|---|
| OpenBao | 3 | Secret管理・Raft |
| `qorynth-node` | 3 | 分散鍵管理・暗号処理 |
| `qorynth-seal` | 2 | OpenBao Auto-Unseal連携 |
| `qorynth-signal` | 3 | P2P接続確立 |
| `qorynth-approval` | 論理 | 端末承認・状態管理 |
| `qorynth` CLI | 任意 | 管理・監視・復旧 |

## セキュリティ設計

| 項目 | 方針 |
|---|---|
| 鍵保護 | 2-of-3閾値暗号 |
| 端末承認 | 3-of-5、WebAuthn / Passkey |
| ノード認証 | mTLS + TPM 2.0 |
| ノード通信 | QUIC / TLS 1.3 |
| 盗難対策 | 鍵分散・ノード失効・起動時ロック |
| 状態同期 | Raft |
| バックアップ | 暗号化・分散・オフライン復旧 |
| 管理 | 固定された中央管理ノードなし |
